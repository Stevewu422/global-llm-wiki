# 认证状态诊断

## 适用场景

Codex 登录方式、额外验证或“刚才改了什么”的只读归因。

## 流程

1. 明确任务是诊断还是修复；未授权时保持 inspect-only。
2. 读取决定认证模式的核心配置字段。
3. 与已知备份或旧基线比较。
4. 在日志数据库中按窄时间窗查找运行时证据。
5. 区分认证状态、插件配置和应用运行时，不把同时改动误判为原因。
6. 输出结论时不暴露任何凭据内容。

## Windows 注意

- 大范围递归搜索噪声高，优先检查核心配置和窄时间窗日志。
- Python 输出日志时显式使用 UTF-8，避免控制台编码错误。
