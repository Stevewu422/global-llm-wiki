## 已验证知识

- 修改仓库前先读取 `AGENTS.md`、README、进度文档和 Git 状态，先辨认真实项目边界。
- 多仓库工作区必须按子仓库分别检查状态，不能把根目录状态误当成全部项目状态。
- 连接已有空 Git 仓库时，先检查现有 `.git` 和 remote，再决定 fetch/checkout；不要默认重新 clone。
- Git 接入验收至少包括 `git status --short --branch`、`git remote -v` 和最新提交回读。
- Windows PowerShell 5 对无 BOM UTF-8 脚本兼容不稳定；自动化脚本文字优先 ASCII，读取 Markdown 时显式指定 UTF-8。
