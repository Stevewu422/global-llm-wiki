# Shared Memory Inbox

Temporary staging area for portable memory candidates that still require
review, deduplication, or verification.

Each candidate should include:

- source Agent
- observation date
- target project/domain
- verification status
- proposed destination

Do not place secrets or private operational data here. After review, merge the
content into a structured page and remove the candidate.
