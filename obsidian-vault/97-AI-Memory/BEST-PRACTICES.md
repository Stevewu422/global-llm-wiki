# 最佳实践

## 任务执行

- 结论先行，复杂任务给短计划后直接推进。
- 能从本地、源系统或权威资料验证时，不依赖猜测。
- 修改前识别真实目标、作用域、现有改动和安全边界。
- 完成后回读文件、状态、日志或用户侧结果。

## 知识管理

- 原始材料进入 Inbox/Archive，验证后再提炼。
- 一个知识点只保留一个 canonical 来源，其余页面用 Wiki 链接引用。
- 只把高复用结论写入长期记忆，细节下沉到项目或 playbook。
- 冲突内容不静默覆盖，保留来源并请求用户裁决。

## Git 与发布

- 操作前检查工作树、分支和 remote。
- 提交前列出并执行验证命令。
- 推送或发布前获得用户确认。

## Windows

- PowerShell 5 读取 UTF-8 Markdown 时显式指定 UTF-8。
- 诊断当前 CPU 热点使用瞬时性能计数器。
- 音频最终以用户实际听见为验收，打印最终区分电脑端发送和实体输出。
