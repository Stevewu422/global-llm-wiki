# Windows 安全诊断

## 性能

1. 采集当前 CPU、内存、磁盘和热点进程。
2. 使用瞬时性能计数器，不用累计 CPU 时间替代当前热点。
3. 仅清理明确范围、超过 24 小时且不在使用中的临时项。
4. 清理收益低时停止扩展范围，报告进程驱动压力。
5. 结束进程、重启服务或设备操作前取得明确授权。

## 音频

1. 确认用户期望的真实设备链。
2. 核对 Audio 服务、静音、音量和默认输出。
3. 查 PnP presence/problem 状态。
4. 必要时升级到管理员级驱动或服务修复。
5. 播放测试音，最终以用户可听见为验收。
