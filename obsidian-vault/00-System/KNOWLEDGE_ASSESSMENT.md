## 当前薄弱领域

1. 美股：缺少公司研究模板、估值框架、持仓与复盘记录。
2. Crypto：缺少链上指标、资产研究和风险监控的持续记录。
3. 设计：缺少品牌规范、组件库和设计决策日志。
4. 自动同步：GitHub remote 已连接，但尚未建立经用户确认的提交/推送节奏。
5. 来源标准化：历史页面已有来源说明，但尚未全部统一为结构化 citation 字段。

## 下一步

1. 为美股、Crypto、设计分别建立标准研究模板。
2. 新项目开始时在 `06-Projects` 建立状态页。
3. 每月运行记忆健康检查并复核过期事实。
4. 用户确认后建立 Git 提交与同步流程。
